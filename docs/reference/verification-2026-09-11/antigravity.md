# Antigravity (Cloud Code v1internal) — verified 2026-09-11

Scope: wire facts for a macOS Rust/Tauri app that signs in with Google OAuth using the Antigravity public OAuth client and calls `cloudcode-pa.googleapis.com/v1internal` the way the reference proxies do. Every value below is quoted from a source read on 2026-09-11 (repo checkouts under `/agent/workspace/research/refs/`, or live fetches). Where references disagree, each value is listed with its date. Anything not found in a primary source is marked **UNVERIFIED**.

Product naming (matters for UA and token-store paths): Google's 2026-05-19 blog calls the new desktop app "Antigravity 2.0" and the terminal tool "Antigravity CLI" (`agy`); the openusage project (PR #508, 2026-05-24) records that "Antigravity now refers to a standalone, agent-first app, while Antigravity IDE is now what was previously known as Antigravity… The standalone app is no longer VSC based, and thus doesn't have a state.vscdb." CLIProxyAPI mimics the "Antigravity Hub" family (UA `antigravity/hub/…`) and pulls its version from an `antigravity-hub` electron-builder manifest.
