Scope: pin the CURRENT wire facts a macOS Rust/Tauri app needs to sign in with a
Claude Pro/Max account via claude.ai OAuth and call the Anthropic Messages API in
the Claude Code wire format so Anthropic's server-side validator classifies it as
first-party (subscription billing) rather than "extra usage".

Everything below was read today from source. Where references disagree, each
value is given with its date. Reverse-engineered wire facts (betas, CCH, headers)
come from third parties diffing the real `claude` binary through a local proxy;
they are marked as such and a fresh capture of the real CLI remains the only
first-party confirmation.

## Items still UNVERIFIED (and what a real-CLI proxy capture would settle)

1. **Exact `cch` algorithm.** griffinmartin/hermes (`SHA256(firstUserText)[:5]`) vs CLIProxyAPI (`xxHash64` over the normalized final body). They disagree and can't both match the real client. A capture of `claude` 2.1.26x through a local proxy, diffing the `cch=` value against both algorithms for the same body, would settle it — and whether cch is even server-verified.
2. **Whether the identity/UA/entrypoint parity alone (not cch) is what flips billing.** Strong circumstantial evidence (hermes #79760 isolates the system identity block; openclaw PR#61 isolates UA + `metadata.user_id` + entrypoint) but no first-party statement. A capture + controlled A/B against api.anthropic.com would confirm the minimal passing set.
3. **Exact current scope set on the loopback flow.** 6 scopes (incl. `org:create_api_key`) per the real 2.1.267 authorize URL (#93216) and pi-ai; CLIProxyAPI's loopback constant sends only 5. A capture of the real `claude auth login` authorize URL settles which is current.
4. **Token-exchange response shape.** Whether `account{uuid,email_address}` / `organization{uuid,name}` are reliably present in the `/v1/oauth/token` response, or only via the follow-up `/api/oauth/profile`. Capture the token response body.
5. **`/api/oauth/usage` field schema.** No official docs; multiple community shapes observed (`five_hour`/`seven_day` object vs `kind`/`group`/`percent` rows). Capture the live response.
6. **Current `X-Stainless-Package-Version` / Node `Runtime-Version` for 2.1.268.** CLIProxyAPI pins 0.112.1 / v26.3.0 for 2.1.258; the SDK version bundled in 2.1.268 may differ. `npm view @anthropic-ai/sdk` inside the 2.1.268 package, or a capture, confirms it. 7. **`redirect_uri` server-side outage.** #93216 (2026-09-09, open) reports Anthropic rejecting even the correct `https://platform.claude.com/oauth/code/callback` for this client_id — a live server-side registration problem that could affect the app's login on day one. Re-check before shipping.
